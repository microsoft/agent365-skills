# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the
[existing issues](https://github.com/microsoft/agent365-skills/issues) before filing
new issues to avoid duplicates. For new issues, file your bug or feature request as a new Issue.

For help and questions about using this project, please refer to the
[Microsoft Agent 365 developer documentation](https://learn.microsoft.com/en-us/microsoft-agent-365/developer/).

To report a security vulnerability, do not file a public issue. Follow the instructions in
[SECURITY.md](./SECURITY.md).

## Microsoft Support Policy

Support for this project is limited to the resources listed above. This is an open-source
project, and Microsoft product support contracts and service-level agreements (SLAs) do not
extend to it.
